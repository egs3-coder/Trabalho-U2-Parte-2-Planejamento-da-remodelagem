FALA — LUCAS (≈45 s) "Cada contexto vira um módulo com três camadas: apresentação, negócio e dados. O ponto importante é a direção das setas: todas apontam para o domínio. A aplicação nunca importa a camada de dados; ela usa interfaces que moram no domínio, como RequisicaoRepository. Quem implementa é a camada de dados, e o Spring injeta a implementação quando sobe. Isso é a inversão de dependência. Para isso não se perder, a esteira roda testes ArchUnit que quebram o build se o domínio importar Spring ou JPA, ou se a aplicação importar dados." SE PERGUNTAREM: "Camada lógica é a mesma coisa que tier?" → Não. Camada é organização do código; tier é onde roda. As três camadas rodam juntas num container; os tiers são navegador, container e banco.
