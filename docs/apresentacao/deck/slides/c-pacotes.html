Camada é como o código se organiza; tier é onde ele roda.

FALA — SAULO (≈45 s) "No código, cada contexto é um pacote com as mesmas três camadas. No exemplo da Requisição, a interface EstoqueGateway fica no domínio e o EstoqueClient, que implementa, fica em dados. Os outros quatro contextos seguem a mesma estrutura. É importante não confundir camada com tier: camada é a organização do código, tier é onde roda. As três camadas rodam juntas no mesmo container; o tier de dados é o servidor PostgreSQL, e o cliente é o navegador ou o app do motorista." SE PERGUNTAREM: "A camada de dados roda no banco?" → Não. O código dos repositórios roda no container, no tier de aplicação; o banco é outro tier.
